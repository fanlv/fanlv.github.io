Your servers.
Your routing rules.

A rule-based proxy client for iPhone and iPad. English and Simplified Chinese. No account, ads, analytics or tracking. Bring your own compatible servers or subscription.

Get connected

  1. On Home, tap + to import a server link or HTTPS subscription, choose a text file, or add a server manually. The QR icon scans supported links.
  2. Tap a server to select it. Choose Website rules, All proxy or All direct on Setup. All direct does not use a proxy.
  3. Read the data-use information on Home, then enable the connection switch. iOS asks to add a VPN configuration on the first connection.
  4. If a connection fails, check credentials and the provider's plan, refresh the subscription, or choose another compatible server. TCP connectivity checks do not verify passwords or browsing speed.

Supported formats

Shadowsocks AEAD/2022, Trojan, VMess AEAD, VLESS, AnyTLS, HTTP and SOCKS5. Import supported server entries from Clash YAML, text files, Base64 link lists and QR codes. Clash policy groups, DNS settings and rule providers are not imported. Hysteria2 and legacy non-AEAD VMess are not supported.

Routing and subscriptions

Rules match exact domains, suffixes, keywords and IPv4/IPv6 CIDRs, with proxy, direct or block actions. Recommended GFWList rules download from GitHub only on request. Refresh subscriptions manually; plan usage and expiry are available when supplied by the provider.

Privacy

Configuration stays in the device keychain. The developer does not collect, sell or disclose usage data. Your chosen proxy and DNS providers handle the connections needed to provide their services. See the full privacy policy for network and retention details.

自己的分流规则。

适用于 iPhone 和 iPad 的规则分流代理客户端，支持简体中文与英文。无需注册，没有广告、统计或追踪。请自行准备兼容节点或订阅。

开始连接

  1. 在首页点 +，导入节点链接、HTTPS 订阅、文本文件，或手动添加节点。扫码图标可识别支持的二维码链接。
  2. 点按节点将其选中，在「配置」选择按网站分流、全部走代理或全部直连。全部直连不使用代理。
  3. 阅读首页数据用途说明后打开连接开关。首次连接由 iOS 请求添加 VPN 配置。
  4. 连接失败时检查节点凭据与服务商套餐，手动更新订阅，或选择其它兼容节点。TCP 连通性测试不验证密码，也不代表实际浏览速度。

支持的格式

支持 Shadowsocks AEAD/2022、Trojan、VMess AEAD、VLESS、AnyTLS、HTTP 和 SOCKS5。可从 Clash YAML、文本、Base64 链接列表和二维码导入受支持的节点。Clash 策略组、DNS 设置和规则提供者不会导入；当前不支持 Hysteria2 与旧版非 AEAD VMess。

规则与订阅

规则支持完整域名、域名后缀、关键词和 IPv4/IPv6 CIDR，动作可选择代理、直连或拦截。只有主动操作时，才会从 GitHub 下载推荐 GFWList。订阅手动刷新；仅在服务商提供时显示套餐用量及到期信息。

隐私

配置保存在本机钥匙串，开发者不收集、出售或向第三方披露使用数据。你选择的代理与 DNS 服务方处理提供服务所必需的连接。网络用途与数据保留详见完整隐私政策。
